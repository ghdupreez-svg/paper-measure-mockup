# Paper Measure Mockup

Standalone mockup for a mobile measurement app concept.

Open `index.html` in a browser. The mockup shows a camera-style workflow where the user tapes an 8.5 x 11 inch sheet of paper to a wall, taps the paper corners for calibration, outlines the target area, and reviews an estimated measurement with confidence.

This is a UX prototype only. It does not use a real camera, ARKit, ARCore, LiDAR, or computer vision yet.
