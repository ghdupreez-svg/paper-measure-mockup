# Paper Measure Mockup

Standalone mockup for a mobile measurement app concept.

Open `index.html` in a browser. The mockup shows a camera-style workflow where the user tapes an 8.5 x 11 inch sheet of paper to a wall, takes or uploads a photo, drags the green handles to the paper corners, drags the gold handles around the area to measure, and reviews a perspective-corrected estimate.

This is a UX prototype only. It can launch the browser camera/photo picker and calculate from same-plane paper calibration, but it does not use ARKit, ARCore, LiDAR, or automatic computer vision yet.
